# FORM & FIELD — Creative Studio

## Project Information

- **Internship:** Oasis Infobyte

- **Track:** Web Development

- **Level:** Level 1

- **Task:** Task 1 — Landing Page

- **Project Type:** Responsive Static Website

## Project Description

FORM & FIELD is a fictional creative studio that helps brands

develop distinctive visual identities and engaging digital

experiences.

This project is a visually polished landing page designed to

demonstrate foundational HTML5 and CSS3 skills. It uses a bold

orange, cream, and black colour palette, strong typography,

project imagery, and a structured layout.

The website is designed to communicate the studio's services,

showcase selected projects, introduce the brand, and encourage

visitors to make contact.

## Technologies Used

- **HTML5:** Structures the webpage and its content.

- **CSS3:** Controls the layout, colours, typography, and styling.

- **CSS Flexbox:** Aligns navigation items and other interface elements.

- **CSS Grid:** Organises the hero, services, projects, and footer.

- **CSS Media Queries:** Adjusts the layout for mobile and tablet screens.

- **Google Fonts:** Provides the DM Sans and Space Grotesk typefaces.

- **GitHub:** Stores and manages the project source code.

No JavaScript is required for this project.

## Features

1. Sticky navigation bar with multiple navigation links.

2. Hero section with a headline, description, and call-to-action buttons.

3. Brand statement section.

4. Services section with three service cards.

5. Selected work section displaying project imagery.

6. About section introducing the fictional studio.

7. Contact section with an email link.

8. Footer containing navigation, contact, and social links.

9. Consistent colour palette and typography.

10. Responsive layouts for desktop, tablet, and mobile screens.

11. CSS hover effects and smooth anchor navigation.

12. Semantic HTML elements and descriptive image alternative text.
