# Arc. Ephraim — Personal Portfolio Website

## Project Overview

This is a personal portfolio website developed to showcase my professional

background, architectural experience, technical skills, projects,

research interests and contact information.

The website presents my interests across architecture, artificial

intelligence, software development, cybersecurity and data analytics.

It was developed as part of the Oasis Infobyte Web Development Internship

(OIBSIP), Task 2 — Personal Portfolio.

## Technologies Used

- HTML5

- CSS3

- JavaScript (Vanilla JavaScript)

- Google Fonts

## Website Features

1. Professional hero section with profile photograph.

2. About Me section.

3. Skills and expertise section.

4. Architectural and software project gallery.

5. Interactive project category filters.

6. Professional experience section.

7. Education section.

8. Research interests and publications.

9. Certifications and training.

10. Leadership and recognition.

11. Languages.

12. Contact information.

13. Responsive mobile navigation.

14. Dark and light theme switcher.

15. Smooth scrolling navigation.

16. Scroll reveal animations.

17. Back-to-top button.

18. Responsive desktop, tablet and mobile layouts.
